# AeroMC 3.0.3

## Türkçe

### Yeni özellikler

- İlk açılışta dört adımlı **Kısa Özellik Turu** ve Ayarlar'dan yeniden başlatma seçeneği eklendi.
- Ana Panel'e kalıcı **Bildirim Merkezi** eklendi: ana aç/kapat, daraltma, okunmamış sayısı, önem filtresi, sunucu ve olay bazlı kurallar, sessiz saatler, tekrar koruması ve deneme bildirimi.
- Son bir saatteki çökme, oyuncu girişi, kapanma ve performans uyarılarını birleştiren **Bildirim Özeti** eklendi.
- Çökme öncesindeki TPS, RAM, CPU ve konsol belirtilerini tek vaka altında toplayan **Olay Zinciri** eklendi.
- Son 7 günlük performans geçmişinden TPS, RAM ve doğrulama süresi öneren **Akıllı Eşik Önerisi** eklendi.

### Sunucu sağlığı ve kullanım kolaylığı

- **Kriz Modu** zaman tabanlı tetikleme, güvenli toparlanma payı, yeniden tetikleme beklemesi, görev duraklatma ve kontrollü ayar geri yükleme ile geliştirildi.
- **Tek Tık Lag Analizi** sadeleştirildi; süre seçimi, canlı geri sayım, Spark kurulum yardımı ve doğrulanmış rapor bağlantısını otomatik yakalama eklendi.
- Bildirimlerde tek ping hatasının sahte açılma/kapanma üretmesini engelleyen iki sonuçlu durum doğrulaması eklendi.
- Linux'taki JavaFX/GDK ile AWT sistem tepsisi çakışması kaldırıldı; masaüstü bildirimleri platforma uygun yönteme geçirildi.

### Güvenlik

- **AeroMC Güvenlik Kalkanı**; dosya izinleri, kimlik kasası, güncelleyici, JAR yolu ve uzaktan erişim izleri için güvenlik puanı ve tek tık izin güçlendirmesi sunuyor.
- Kritik ve hassas konsol komutlarına risk sınıflandırması ile ikinci onay eklendi; uzaktan genel komut alanı yalnızca düşük riskli komutlarla sınırlandı.
- Uzaktan erişime CSRF koruması, nonce tabanlı CSP, çerçeveleme engeli, 4 KiB istek sınırı ve IP başına işlem hız sınırı eklendi.
- Sunucu, dosya, yedek ve dünya işlemlerinde kök dışına çıkma ve simgesel bağlantı kaçışı engellendi.
- Beş dakika içinde üçüncü yerel çökmede otomatik yeniden başlatmayı geçici kilitleyen **Çökme Döngüsü Kalkanı** eklendi.
- Dünya ZIP geri yüklemesine geçici çıkarma alanı, 100 bin dosya ve 20 GiB açılmış boyut sınırı ile güvenli geri dönüş eklendi.
- Hassas ayar dosyaları atomik kaydediliyor ve desteklenen sistemlerde daha sıkı dosya izinleri kullanıyor.

### Güncelleme ve kurulum

- Güncelleme paketini açarken oluşabilen arayüz çökmesi giderildi; kurucu arka plan görevinde işletim sisteminin güvenli dosya açıcısıyla başlatılıyor.
- Kurulum sihirbazına güncel resmî Minecraft EULA ve Kullanım Kuralları bağlantıları eklendi. `eula=true` yalnızca açık kullanıcı onayından sonra yazılıyor.
- AeroMC kurucusunun gösterdiği sözleşme 3.0.3 için güncel, Türkçe ve İngilizce `INSTALLER-EULA.txt` ile değiştirildi.
- README artık Türkçe ve İngilizce sunuluyor.

## English

### New features

- Added a four-step **Quick Feature Tour** on first launch, with an option to reopen it from Settings.
- Added a persistent **Notification Center** to the Dashboard with master enable/disable, collapse, unread count, severity filter, per-server and per-event rules, quiet hours, duplicate protection, and test notifications.
- Added a **Notification Summary** that groups crashes, player joins, shutdowns, and performance warnings from the last hour.
- Added **Incident Chains** that combine TPS, RAM, CPU, and console symptoms leading up to a crash.
- Added **Smart Threshold Suggestions** based on seven days of performance history.

### Server health and usability

- Improved **Crisis Mode** with time-based triggering, safe recovery margins, retrigger cooldown, task pausing, and controlled restoration of server settings.
- Simplified **One-Click Lag Analysis** with duration presets, a live countdown, Spark setup help, and automatic capture of verified report links.
- Added two-result state confirmation so one failed ping cannot create false online/offline notifications.
- Removed the Linux JavaFX/GDK and AWT SystemTray conflict by using platform-appropriate desktop notification methods.

### Security

- Added the **AeroMC Security Shield** with a score for file permissions, credential vaults, updater state, JAR paths, and remote-access artifacts, plus one-click permission hardening.
- Added risk classification and second confirmation for sensitive/critical console commands; generic remote commands are limited to low-risk actions.
- Hardened Remote Access with CSRF protection, nonce-based CSP, frame blocking, a 4 KiB request limit, and per-IP action rate limiting.
- Blocked parent traversal and symbolic-link escape in server, file, backup, and world operations.
- Added a **Crash Loop Shield** that temporarily locks automatic restart after the third local crash within five minutes.
- Hardened world ZIP restoration with staging extraction, a 100,000-entry limit, a 20 GiB decompressed-size limit, and rollback protection.
- Sensitive settings now use atomic writes and stricter permissions on supported operating systems.

### Updates and installation

- Fixed a possible UI crash while opening a downloaded update installer; the installer now launches in a background task through the operating system's safe file opener.
- Added current official Minecraft EULA and Usage Guidelines links to the server setup wizard. `eula=true` is written only after explicit user acceptance.
- Replaced the installer agreement with the current bilingual `INSTALLER-EULA.txt` for version 3.0.3.
- The README is now available in both Turkish and English.

## Known limitations / Bilinen sınırlamalar

- Release packages are currently unsigned and may show Windows SmartScreen or macOS Gatekeeper warnings.
- LAN Remote Access uses local HTTP and must not be exposed directly to the internet.
- Update packages are verified with SHA-256; publisher-key signatures are planned for a later release.
- The device-bound AES vault is not yet backed by Windows Credential Manager, macOS Keychain, or Linux Secret Service.
