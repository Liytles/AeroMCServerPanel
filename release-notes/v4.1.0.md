# AeroMC v4.1.0

## Türkçe

Bu sürüm, 4.1 beta sürecindeki kararlılık düzeltmelerini ve çoklu sağlayıcı yönetimini resmî sürüme taşır.

- Yerel JAR sunucularında güvenli kapatma/yeniden başlatma kuyruğu ve portu tutan işlem tanılama eklendi.
- Pterodactyl haftalık raporu artık yalnızca Pterodactyl filo verisini kullanır; canlı konsoldan oyuncu listesi alınır.
- AeroMC ana parolası ilk kullanımda zorunludur. İsteğe bağlı olarak her açılışta istenebilir.
- Ayarlar AES-256-GCM ile şifrelenmiş `.aeromc-settings` dosyasına aktarılıp başka bir AeroMC kurulumuna geri yüklenebilir.
- Ayar aktarımı güvenlik için dünyaları, günlükleri, ana parola doğrulamasını ve cihaza bağlı otomatik kasaları içermez.
- İngilizce arayüzde kalan yeni ayar metinleri çevrildi.

### Kurulum

- **Windows:** `.exe` dosyasını indirip çalıştır.
- **Linux (Debian/Ubuntu):** `.deb` dosyasını indirip sistem paket yöneticisiyle kur.
- **macOS:** `.dmg` dosyasını açıp AeroMC’yi Applications klasörüne taşı.

Her paket gömülü Java çalışma zamanı içerir; ayrıca Java kurman gerekmez.

## English

This release promotes the stability fixes and multi-provider improvements from the 4.1 beta cycle to a stable release.

- Added a safe stop/restart queue and process diagnostics for local JAR server ports.
- Pterodactyl weekly reports now use only Pterodactyl fleet data, and player lists are read from the live console.
- An AeroMC master password is required on first use and can optionally be requested on every launch.
- Settings can be exported to and restored from an AES-256-GCM encrypted `.aeromc-settings` file.
- For safety, settings transfers exclude worlds, logs, the master-password verifier, and device-bound automatic vaults.
- Remaining new settings text is translated in the English interface.

### Installation

- **Windows:** Download and run the `.exe` installer.
- **Linux (Debian/Ubuntu):** Download the `.deb` package and install it with your package manager.
- **macOS:** Open the `.dmg` and move AeroMC to Applications.

Every installer bundles a Java runtime; no separate Java installation is required.
