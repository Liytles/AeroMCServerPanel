# AeroMC 4.0.0

## Türkçe

AeroMC 4, paneli yalnızca Yerel JAR ve Exaroton yöneten bir uygulama olmaktan çıkarıp ortak bir sağlayıcı modeli kullanan çoklu sunucu yönetim merkezine dönüştürüyor. Bu büyük sürüm; Pterodactyl Client API desteği, AeroGuard V2.2 güvenlik katmanı, daha akıcı arayüz ve kapsamlı Türkçe/İngilizce düzeltmeleri getiriyor.

### Pterodactyl Client API

- `ptlc_...` Client API anahtarıyla erişilebilen Pterodactyl sunucularını listeleme ve seçme eklendi.
- Başlatma, durdurma, yeniden başlatma, onaylı zorla kapatma ve konsol komutu işlemleri destekleniyor.
- CPU, RAM, disk, çalışma süresi ve sunucu adresi canlı olarak izleniyor.
- Canlı konsol, API anahtarını WebSocket'e göndermeden Pterodactyl'in kısa ömürlü WebSocket biletiyle çalışıyor.
- Seçilen Pterodactyl sunucusu Yönetim, Canlı Harita ve Kontrol Merkezi araçlarında ortak sağlayıcı olarak kullanılabiliyor.
- `server.properties` ve izin verilen temel yapılandırmalar Client API üzerinden güvenli biçimde okunup yazılabiliyor.
- Uzak panellerde HTTPS zorunlu; yönlendirmeler anahtar sızıntısını önlemek için izlenmiyor.

### AeroGuard V2.2

- Güvenlik bileşenleri ayrı `aeroguard` paketinde toplandı ve uygulama başlığında sürekli görünen AeroGuard rozeti eklendi.
- Rozet tıklandığında aktif korumaları seçilen arayüz dilinde açıklayan bilgi ekranı açılıyor.
- Exaroton/Pterodactyl anahtarları ve Discord webhook'ları isteğe bağlı cihaz/kullanıcı bağlı AES-256-GCM kasasında saklanabiliyor.
- SafePathGuard, kök dışına çıkma ve simgesel bağlantı kaçışlarını yerel dosya, yedek ve dünya işlemlerinde engelliyor.
- Kritik konsol ve güç işlemleri ikinci onaydan geçiyor; gizli alanlarda kopyalama, kesme, sağ tık ve sürükleme sınırlandırılıyor.
- TLS 1.2/1.3 uzaktan erişim, RSA-3072 cihaz sertifikası, CSRF, nonce tabanlı CSP, istek sınırı, hız sınırı, rol yetkileri, güvenlik günlüğü ve çökme döngüsü kalkanı birlikte korunuyor.

### Performans ve kararlılık

- Konsol satırları sınırlı ve toplu işlenen tamponlarla JavaFX arayüzüne aktarılıyor; sınırsız metin büyümesi engellendi.
- Exaroton ve Pterodactyl konsollarındaki gereksiz iç içe `runLater` çağrıları kaldırıldı.
- Pterodactyl kaynak yenilemesi ve Kontrol Merkezi ölçümleri daha dengeli aralıklara alındı.
- Favori sunucu kartlarında üst üste binen ping istekleri engellendi.
- Otomatik kaydırma yalnızca kullanıcı konsolun sonuna yakınken yapılıyor; geçmiş satırlar incelenirken görünüm zıplamıyor.

### Arayüz ve dil

- Exaroton Sunucu Kontrolü, Filo Paneli, Kredi Koruması ve Otomasyon Merkezi tamamen Türkçe/İngilizce dil sistemine bağlandı.
- Aternos ve Pterodactyl ekranlarındaki sabit Türkçe metinler çevrildi.
- Sağlayıcılar tek **Sunucular** alanında; ortak araçlar Yönetim, Canlı Harita ve Kontrol Merkezi'nde düzenlendi.
- AeroGuard logosunun arka planı panel temasıyla uyumlu hale getirildi.

### Kurulum ve güvenlik notları

- Pterodactyl için yalnızca **Client API** anahtarı kullanın; Application API anahtarları desteklenmez.
- Uzak Pterodactyl panel adresi geçerli HTTPS sertifikasına sahip olmalıdır.
- Windows `.exe`, Linux `.deb` ve macOS `.dmg` paketleri kendi Java çalışma zamanını içerir.
- Her kurucunun yanında aynı adlı `.sha256` dosyası yayımlanır. AeroMC Güncelleme Merkezi paketi açmadan önce bu özeti doğrular.
- İlk paketler kod imzasızdır; Windows SmartScreen veya macOS Gatekeeper yayımlayıcı uyarısı gösterebilir.

## English

AeroMC 4 turns the panel from a Local JAR and Exaroton-focused application into a multi-server management center built on a shared provider model. This major release adds Pterodactyl Client API support, the AeroGuard V2.2 security layer, a more responsive UI, and comprehensive Turkish/English localization fixes.

### Pterodactyl Client API

- List and select servers available to a `ptlc_...` Client API key.
- Start, stop, restart, confirmed force-kill, and console-command operations are supported.
- Monitor CPU, RAM, disk, uptime, and server address in real time.
- The live console uses Pterodactyl's short-lived WebSocket ticket without sending the API key to the WebSocket connection.
- The selected Pterodactyl server is available as a shared provider in Management, Live Map, and Control Center tools.
- Read and update `server.properties` and approved core configuration files safely through the Client API.
- HTTPS is required for remote panels, and redirects are not followed with credentials attached.

### AeroGuard V2.2

- Security components now live in a dedicated `aeroguard` package, with a persistent AeroGuard badge in the application header.
- Clicking the badge opens a localized explanation of the active protections.
- Exaroton/Pterodactyl keys and Discord webhooks can optionally be stored in a device/user-bound AES-256-GCM vault.
- SafePathGuard blocks parent traversal and symbolic-link escapes across local file, backup, and world operations.
- Critical console and power actions require confirmation; copy, cut, context-menu, and drag extraction are restricted on secret fields.
- TLS 1.2/1.3 remote access, an RSA-3072 device certificate, CSRF, nonce-based CSP, body/rate limits, role permissions, audit logging, and Crash Loop Shield remain enforced together.

### Performance and stability

- Console output is delivered to JavaFX through bounded, batched buffers, preventing unbounded text growth.
- Redundant nested `runLater` calls were removed from Exaroton and Pterodactyl console paths.
- Pterodactyl resource refresh and Control Center sampling now use calmer intervals.
- Favorite-server cards prevent overlapping ping requests.
- Auto-scroll occurs only while the user is already near the end of the console, so inspecting history no longer causes jumps.

### Interface and localization

- Exaroton Server Control, Fleet Panel, Credit Protection, and Automation Center are fully connected to the Turkish/English language system.
- Remaining hard-coded Turkish text in Aternos and Pterodactyl views was localized.
- Providers are grouped under **Servers**, with shared tools organized under Management, Live Map, and Control Center.
- The AeroGuard logo background now matches the panel theme.

### Installation and security notes

- Use a **Client API** key for Pterodactyl; Application API keys are not supported.
- Remote Pterodactyl panel URLs must have a valid HTTPS certificate.
- Windows `.exe`, Linux `.deb`, and macOS `.dmg` packages bundle their own Java runtime.
- A matching `.sha256` file is published beside each installer. AeroMC Update Center verifies it before opening the package.
- Initial packages are unsigned, so Windows SmartScreen or macOS Gatekeeper may show publisher warnings.
