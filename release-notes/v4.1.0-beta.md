# AeroMC 4.1.0-beta

> **Ön sürüm / Pre-release:** Bu sürüm gerçek sunucularda test edilmek içindir. Kritik sunucularda önce yedek alıp kararlı 4.0.0 sürümünü hazır tutun.

## Türkçe

### Oyun Yardımcısı

- **Araçlar → Oyun Yardımcısı** altında, Minecraft'a mod kurmadan çalışan küçük ve her zaman üstte duran yardımcı pencere eklendi.
- Yerel JAR, Exaroton ve Pterodactyl için durum, oyuncu sayısı ve kaynak bilgisi gösterir; beş saniyede bir yenilenir.
- Pencereden en fazla 160 karakterlik, güvenli `tellraw` duyurusu gönderilebilir.
- API anahtarları ayrı bir pencereye aktarılmaz; yalnız AeroMC'nin güvenli kasasında/uygulama belleğinde kalır.

### Sunucu Profilleri

- **Araçlar → Sunucu Profilleri** altında Arkadaş SMP, Performans, Bakım ve Ekonomi profilleri eklendi.
- Her profil önce değiştireceği TPS/RAM Kriz Modu eşiklerini ve ilgili güvenli tercihleri açıkça gösterir, ardından onay ister.
- Yerel RAM değişikliği bir sonraki başlatmada uygulanır.
- Exaroton profilleri yalnızca güvenli tercihleri hazırlar; otomasyonu veya kredi eşiğinde sunucuyu durdurmayı kendi kendine etkinleştirmez.

### Oyun içi AeroMC komutları

- OP'ler için `.aeromc sağlık`, `performans`, `oyuncular`, `kriz`, `durum`, `yardım` ve `.aeromc duyur <mesaj>` akışı iyileştirildi.
- Sağlık çıktısı yinelenen durumu tek yanıtta toplar; yerel oyuncu sayısı panelde farklı sağlayıcı açık olsa bile yenilenir.
- Yerel performans yanıtı, kullanılabiliyorsa Java işleminin CPU/RSS bellek örneğini kullanır.

### Dil ve kararlılık

- Oyun Yardımcısı ve Sunucu Profilleri Türkçe/İngilizce arayüz altyapısına bağlandı.
- Uzak sağlayıcı çağrılarındaki hata durumları kullanıcıya doğru çevrilir; arayüzde anahtar veya ham gizli veri gösterilmez.

## English

### Game Helper

- Added a small, always-on-top helper window under **Tools → Game Helper** that works without installing a Minecraft mod.
- It shows status, player count, and resources for Local JAR, Exaroton, and Pterodactyl; refreshes every five seconds.
- It can send a safe, 160-character `tellraw` announcement.
- API keys are never transferred to the helper window; they remain in AeroMC's secure vault or application memory.

### Server Profiles

- Added Friends SMP, Performance, Maintenance, and Economy profiles under **Tools → Server Profiles**.
- Each profile previews its Crisis Mode thresholds and related safe preferences, then asks for confirmation.
- Local RAM adjustments apply on the next server start.
- Exaroton profiles only prepare safe preferences; they never automatically enable automation or threshold-triggered stopping.

### In-game AeroMC commands

- Improved the OP-only `.aeromc health`, `performance`, `players`, `crisis`, `status`, `help`, and `.aeromc announce <message>` flow.
- Health consolidates repeated status information, and Local player count refreshes even while another provider view is open.
- Local performance uses a direct Java-process CPU/RSS memory sample when available.

### Language and stability

- Game Helper and Server Profiles are connected to the Turkish/English UI infrastructure.
- Remote-provider failures are surfaced cleanly without exposing keys or raw secret data.
